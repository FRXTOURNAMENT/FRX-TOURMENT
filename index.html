¿Cómo participar?

1. Contacta al organizador para recibir tu código único de capitán.

2. Ingresa tu código en la página de INICIO para inscribir tu equipo.

3. Después de cada partida, sube la captura de pantalla con los resultados.

4. El admin revisa y aprueba las capturas para actualizar el ranking.


Sistema de puntos Match Point

🥇 1er lugar = 15 pts  ·  🥈 2do = 12 pts  ·  🥉 3ro = 10 pts

4to = 8pts · 5to = 7pts · 6to = 6pts · 7mo = 5pts · 8vo = 4pts

9no = 3pts · 10mo = 2pts · 11-15 = 1pt · 16+ = 0pts

+ 1 punto extra por cada kill del equipo en la partida.


¿Cuándo termina?

El primer equipo en llegar a 120 puntos gana el torneo.
